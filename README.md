# Schoolmanagement

Schoolmanagement est une application dédiée à la gestion efficace des établissements scolaires. Ce projet permet d'administrer les étudiants, enseignants, matières, classes et évaluations via une interface conviviale.

## Fonctionnalités

- Gestion des étudiants (ajout, modification, suppression)
- Gestion des enseignants
- Gestion des matières et des programmes
- Gestion et attribution des classes
- Gestion des notes et bulletins
- Authentification et gestion des rôles (admin, enseignant, élève)
- Tableau de bord statistique

## Technologies utilisées

Le projet est principalement composé des éléments suivants: :

- Backend :Java (Spring Boot)
